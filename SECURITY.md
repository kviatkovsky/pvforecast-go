# Security policy

## Supported versions

Security fixes are released for the latest minor version only.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them
privately through GitHub's
[private vulnerability reporting](https://github.com/kviatkovsky/pvforecast-go/security/advisories/new).

You will get an acknowledgement within 7 days. Once the issue is confirmed, a
fix and a GitHub Security Advisory are published together, crediting you
unless you prefer otherwise.
